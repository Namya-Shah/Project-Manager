# How to Apply the Database Fix

The `DATABASE_FIX.sql` file contains the necessary SQL commands to fix the missing columns and reload the schema cache.

## Steps to Run

1.  **Copy SQL Code**
    - Open `DATABASE_FIX.sql` in your editor.
    - Copy all the content.

2.  **Open Supabase SQL Editor**
    - Click this link to go directly to your project's SQL editor:
    - [Supabase SQL Editor](https://supabase.com/dashboard/project/lcbweinvnmcxptttvtvz/sql/new)
    - *(Note: You may need to log in)*

3.  **Run Script**
    - Paste the code into the editor.
    - Click the **"Run"** button (bottom right or top bar).

4.  **Verify**
    - Ensure you see a "Success" message or no errors.

5.  **Restart App**
    - Reload your application browser tab.
    - The Team functionality and Real-time logs should now work perfectly.
